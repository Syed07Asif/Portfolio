# types/

- `database.ts` — generated by the Supabase CLI from the `public` schema. Reflects every column exactly; never imported outside this folder. Regenerate after any migration change (command in the file's header comment).
- `content.ts` — hand-authored domain types (`Profile`, `Project`, `ProjectDetail`, etc.) derived from `database.ts`, matching exactly what each `lib/data` function selects. **Components and `lib/data` import from here, never from `database.ts` directly.**

Zod validation schemas live in `lib/validation/`, not here — they're the single source of truth for form/server validation and are derived from these same domain types.
